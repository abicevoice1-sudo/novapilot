# Security policy

## Reporting a vulnerability

**Do not file public GitHub issues for security problems.** Report privately to the maintainer (see repo profile). Include: affected version, reproduction steps, and impact assessment.

We aim to acknowledge within 72 hours and will coordinate a fix within a 90-day disclosure window.

## Scope

NovaPilot is a security-sensitive application (private memories, credentials, browser sessions, code execution). The threat model lives in `docs/security.md`. Out of scope: other users' deployments, social engineering, physical access.
